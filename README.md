# 🏃 Pace

Aplicación Android de seguimiento de hábitos diarios con funcionalidades sociales en tiempo real. 
Permite a los usuarios gestionar sus hábitos, visualizar su historial y conectarse con otros a través de "Círculos" (grupos de chat temáticos).

## 📌 Características

- Registro y seguimiento de hábitos diarios con categorías y franjas horarias (mañana, tarde, noche)
- Historial de hábitos con vista de calendario interactivo
- Círculos: grupos de chat en tiempo real donde los miembros pueden enviarse mensajes, fotos y crear eventos compartidos
- Sistema de eventos dentro de los chats: creación, respuesta y activación automática programada
- Gestión de perfil con foto de usuario (recorte y subida a Supabase)
- Ajustes de cuenta: cambio de contraseña, idioma, tema claro/oscuro, gestión de dispositivos activos y usuarios bloqueados
- Autenticación con email/contraseña y Google Sign-In
- Notificaciones de recordatorio de hábitos programadas
- Soporte multilingüe (español, inglés, francés)

## ⚙️ Tecnologías usadas

- **Lenguaje:** Kotlin
- **Plataforma:** Android (minSdk 24, targetSdk 36)
- **Base de datos en tiempo real:** Firebase Realtime Database
- **Autenticación:** Firebase Auth (email + Google Sign-In)
- **Almacenamiento de archivos:** Supabase Storage (fotos de chat y perfil)
- **UI:** Material Design 3, ViewBinding, DrawerLayout
- **Notificaciones:** WorkManager + AlarmManager
- **Serialización:** Gson
- **Recorte de imágenes:** UCrop
